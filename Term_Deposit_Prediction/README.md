Task 1: Term Deposit Subscription Prediction

Objective
Predict whether a bank customer will subscribe to a term deposit after a marketing campaign.

Dataset
UCI Bank Marketing Dataset

Techniques Used
* Data Cleaning
* Label Encoding
* Logistic Regression
* Random Forest Classifier

Evaluation Metrics
* Confusion Matrix
* F1 Score
* ROC Curve

Explainable AI
Used **LIME** to explain 5 model predictions and identify influential features.

Result
Random Forest performed better than Logistic Regression in prediction accuracy.

Skills Gained
* Classification Modeling
* Feature Encoding
* Model Evaluation
* Explainable AI (LIME)
* Customer Behavior Analysis

Tools
Python, Google Colab, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, LIME
